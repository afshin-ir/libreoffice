# لیبره‌آفیس فارسی | سایت و وبلاگ

این مخزن شامل صفحهٔ فارسیِ معرفی مجموعهٔ اداری لیبره‌آفیس و وبلاگی برای نوشته‌های آموزشی، خبرها و تجربه‌های کار با آن است.

## 🏠 صفحهٔ اصلی

در [صفحهٔ اصلی سایت](index.html) با مجموعهٔ لیبره‌آفیس و ابزارهای آن آشنا می‌شوید:

- **رایتر** برای نوشتن و ویرایش متن
- **کَلک** برای صفحه‌گسترده، محاسبه و نمودار
- **ایمپرس** برای ساخت ارائه
- **دراو** برای طراحی و ترسیم
- **بیس** برای مدیریت پایگاه داده
- **مَث** برای نوشتن فرمول‌های ریاضی

صفحهٔ اصلی همچنین دربارهٔ مزیت‌های لیبره‌آفیس، جامعهٔ جهانی آن و راه‌های مشارکت در زمینه‌هایی مانند بومی‌سازی، مستندسازی، طراحی و توسعه می‌گوید. از پیوندهای صفحه می‌توان به دریافت نرم‌افزار، راهنماها و اطلاعات جامعه رسید.

## ✍️ وبلاگ فارسی

[آرشیو وبلاگ](blog/index.html) نوشته‌ها را در یک فهرست گرد هم می‌آورد. امکانات آن عبارت‌اند از:

- 🔎 جست‌وجو در نوشته‌ها و پالایش آن‌ها بر پایهٔ دسته‌بندی
- 📚 صفحه‌بندی فهرست نوشته‌ها
- 📅 نمایش تاریخ‌ها به گاه‌شماری جلالی و نام نویسنده در صفحهٔ هر نوشته
- ↔️ پیوند به نوشتهٔ قدیمی‌تر و جدیدتر برای ادامهٔ خواندن
- 🖼️ بزرگ‌نمایی عکس‌ها با کلیک؛ زیرنویس و متن جایگزین نیز به درک تصویر کمک می‌کنند
- 📡 [خوراک RSS وبلاگ](blog/feed.xml) برای دنبال‌کردن نوشته‌های تازه در RSSخوان‌ها
