# آرشیو استاتیکیِ وبلاگ لیبره‌آفیس فارسی

این سایت از خروجی WordPress WXR ساخته شده است.

- 201 نوشتهٔ منتشرشده تبدیل شده‌اند به صفحه‌های HTML.
- مسیرهای مقاله تا جای ممکن مطابق نشانی‌های قبلی وبلاگ ساخته شده‌اند.
- فهرست مطالب قابلیت جست‌وجو و پالایش بر پایهٔ دسته دارد.
- دیدگاه‌های تأییدشده به‌صورت آرشیوی نمایش داده می‌شوند.
- فایل WXR شامل خودِ رسانه‌ها نیست؛ ارجاع‌های مقاله‌ها به نشانی‌های اصلی رسانه حفظ شده‌اند.
- پیش‌نویس‌ها و مطالب زباله‌دان برای انتشار عمومی وارد سایت نشده‌اند.

برای فعال‌کردن GitHub Pages، در تنظیمات مخزن مسیر انتشار را روی شاخهٔ `main` و پوشهٔ ریشه بگذارید. نشانی پروژه پس از انتشار: `https://afshin-ir.github.io/libreoffice/`.
