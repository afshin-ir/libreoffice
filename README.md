# آرشیو استاتیکیِ وبلاگ لیبره‌آفیس فارسی

این سایت از خروجی WordPress WXR ساخته شده است.

- 203 نوشتهٔ منتشرشده تبدیل شده‌اند به صفحه‌های HTML.
- نشانی هر نوشته عددی است؛ مانند `/blog/203.html`.
- فهرست مطالب قابلیت جست‌وجو و پالایش بر پایهٔ دسته دارد.
- دیدگاه‌های تأییدشده به‌صورت آرشیوی نمایش داده می‌شوند.
- فایل WXR شامل خودِ رسانه‌ها نیست؛ ارجاع‌های مقاله‌ها به نشانی‌های اصلی رسانه حفظ شده‌اند.
- پیش‌نویس‌ها و مطالب زباله‌دان برای انتشار عمومی وارد سایت نشده‌اند.

برای فعال‌کردن GitHub Pages، در تنظیمات مخزن مسیر انتشار را روی شاخهٔ `main` و پوشهٔ ریشه بگذارید. نشانی پروژه پس از انتشار: `https://afshin-ir.github.io/libreoffice/`.

## هنگام افزودن نوشتهٔ تازه

- شمارهٔ بعدی را به نشانی و نام فایل بده و عنوان صفحه را فقط عنوان نوشته بگذار.
- در `<head>` برای هر نوشته یک `meta description` کوتاه، دقیق و یکتا بنویس و `meta keywords` را با چند عبارت واقعاً مرتبط با همان نوشته کامل کن.
- نام نویسنده را «افشین فلاطونی» ثبت کن و تاریخ را در متن صفحه جلالی بنویس؛ مقدار `datetime` را به قالب استاندارد میلادی نگه دار.
- زیر هر نوشته، پیوندهای ثابت به نوشتهٔ قدیمی‌تر و جدیدتر را بر پایهٔ شمارهٔ عددی اضافه کن.
- برای تصویرها متن جایگزین توصیفی بگذار و فایل‌های تصویری را با اندازهٔ واکنش‌گرا در محتوا نمایش بده.
- فهرست جست‌وجو، نقشهٔ سایت و `blog/feed.xml` را هم با نوشتهٔ تازه به‌روز کن.
