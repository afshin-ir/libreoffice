فونت دلخواه برای فرمول‌های ریاضی

2023-03-18نویسنده: afshin
واژه‌پرداز
برنامهٔ Libreoffice Math برای درج فرمول‌ها و معادلات ریاضی از فونت OpenSymbol استفاده می‌کند و متأسفانه به‌دلیل ضعف‌های ساختاری‌اش اجازه هم نمی‌دهد که آن را به فونت دلخواهتان عوض کنید! دو راه برای حل این مشکل هست که یکی آسان و فقط کار راه‌انداز و دیگری کمی سخت، اما دقیق و فنی است. راه آسان: به مسیر زیر بروید و مطابق عکس عمل کنید:

Tools → Options → LibreOffice → Fonts
